# 딥러닝 음성 잡음 제거 (2026 신호 및 시스템 2차 챌린지)

STFT 스펙트럼에서 복소 마스크를 예측하는 모델 5개를 가중 평균하는 앙상블입니다.
**학습 없이** `weights/`의 가중치만 불러와 `input/`의 noisy 음성을 처리합니다.

| 항목 | 값 |
| :--- | :--- |
| 검증 평균 PESQ-WB (164개) | **2.8269** (앙상블 + 시간 이동 TTA) |
| 참고: TTA 없이 | 2.8194 |
| 참고: noisy 입력 | 1.3947 |

## 실행 환경

- Python 3.10 이상 (3.12에서 확인)
- 패키지 설치: `pip install -r requirements.txt`
- GPU가 있으면 자동으로 사용하고, 없으면 CPU로 실행합니다.
- 추론 중 추가 다운로드는 없습니다. 모델 코드(`model.py`)와 가중치(`weights/`)가 저장소에 포함되어 있습니다.

## 추론 실행 (input/ → output/)

1. 테스트 WAV(16 kHz 모노)를 `input/` 폴더에 넣습니다.
2. 저장소 최상위 폴더에서 실행합니다.

```
python inference.py
```

3. `output/` 바로 아래에 입력과 **같은 파일명, 16 kHz 모노, 같은 표본 수**로 저장됩니다.

**노트북으로 실행할 때:** `deep_learning_noise_reduction.ipynb`를 저장소 최상위 폴더에서 열고 위에서부터 모든 셀을 실행합니다. `inference.py`와 같은 결과를 냅니다.

모든 경로는 `inference.py`의 위치를 기준으로 정해지므로 **절대 경로를 수정할 필요가 없습니다.**

| 옵션 | 설명 |
| :--- | :--- |
| `--input 경로`, `--output 경로` | 입력·출력 폴더 변경 |
| `--no-tta` | 시간 이동 TTA를 끄고 약 4배 빠르게 실행 (검증 PESQ 약 0.0075 낮음) |
| `--device cpu` | 장치 직접 지정 |

## 모델 구성

모든 모델은 16 kHz 파형을 STFT(Hann 512, hop 128)로 바꾸고, 복소 마스크를 noisy 스펙트럼에 곱한 뒤 iSTFT로 복원합니다.

| 이름 | 구조 | 파라미터 | 검증 PESQ-WB | 앙상블 비중 |
| :--- | :--- | ---: | ---: | ---: |
| dpcrn_large | DPCRN (Conv2d 인코더·디코더 + 이중 경로 BiLSTM 블록 3개, 채널 96) | 1,379,426 | 2.7312 | 0.45 |
| dpcrn_a | DPCRN (이중 경로 BiLSTM 블록 2개, 채널 64) | 580,642 | 2.7063 | 0.30 |
| dpcrn_b | dpcrn_a와 같은 설정으로 다시 학습 | 580,642 | 2.6344 | 0.15 |
| bilstm_a | Conv1d + 2층 BiLSTM, 복소 마스크 | 3,091,460 | 2.2772 | 0.05 |
| bilstm_b | bilstm_a와 같은 설정으로 다시 학습 | 3,091,460 | 2.2539 | 0.05 |

- **이중 경로 RNN:** 한 블록 안에서 주파수 방향 BiLSTM(프레임 안 주파수 빈 사이 관계)과 시간 방향 BiLSTM을 번갈아 적용합니다.
- **복소 마스크:** 마스크 크기를 tanh로 1 이하로 제한하고, 위상 회전은 자유롭게 학습합니다.
- **시간 이동 TTA:** 입력을 0·32·64·96 표본 밀어 각각 처리한 뒤 평균합니다. 입력은 noisy 음성만 사용합니다.
- 앙상블 구성과 비중은 `weights/ensemble.json`에 있습니다.

## 학습 설정 (공통)

| 항목 | 값 |
| :--- | :--- |
| 데이터 | 배포된 Train 1,296쌍만 사용 (외부 데이터·잡음 재합성 없음), Validation으로 가중치 선택 |
| 입력 특징 | 압축 크기 \|Y\|^0.3 (DPCRN은 압축 실수·허수부 포함 3채널) |
| 손실 | 압축 스펙트럼 손실: 0.7 × 압축 크기 MSE + 0.3 × 압축 복소 MSE (압축 지수 0.3) |
| 옵티마이저 | AdamW, lr 0.001, weight decay 1e-4, batch 8, gradient clipping 5.0 |
| 학습률 조정 | 검증 PESQ 기준 ReduceLROnPlateau (factor 0.5, patience 5, 최소 1e-5) |
| 조기 종료 | 최소 30 epoch, 검증 PESQ 0.001 이상 개선이 없으면 종료 |
| 가중치 선택 | 검증 평균 PESQ-WB가 가장 높은 epoch |

## 학습 재현

학습에 사용한 원본 노트북은 `training/train_notebook.ipynb`에 있습니다. 학습·검증 데이터는 개인 음성이 포함되어 있어 저장소에 포함하지 않았습니다.
배포 데이터의 `train/`, `validation/`을 노트북과 같은 폴더에 두면 자동으로 찾습니다.
3.2절 모델 정의 셀의 마지막 줄(`MaskCNN = DPCRNLarge` 등)로 학습할 모델을 고르고 4.2절을 실행합니다.
학습이 끝나면 `outputs/best_mask_cnn.pt`를 `weights/`에 위 표의 파일명으로 복사합니다.
